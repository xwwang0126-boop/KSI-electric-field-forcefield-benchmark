File descriptions

Files named 19nt.* correspond to the parameter files of the small molecule 19-nortestosterone.

5kp4leap.pdb is the crystal structure file, and model1.pdb–model8.pdb are near-crystal structures extracted from molecular dynamics simulations.

aptraj.in is the input file used for cpptraj to calculate hydrogen-bond distances.

Files named electricfiledall.* are programs related to electric field calculations.

min1.in, min2.in, heat.in, and md.in are input files used for molecular dynamics simulations.

Files named tleap* are used to generate topology files.

ptrajcrd.in is an input file for cpptraj, used to image the protein and water molecules into the simulation box.
